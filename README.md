# 🎬 Netflix Data Analysis & Visualization Project

An end-to-end data analytics project showcasing data extraction, cleaning, querying, and interactive visualization using **Python (Pandas, NumPy), MySQL, and Power BI**.

---

## 🚀 Project Workflow & Architecture
1. **Data Cleaning & Preprocessing (Python):** 
   - Used **Pandas** and **NumPy** to handle missing values, clean text data, remove duplicates, and format date-time columns.
2. **Database Management & Exploratory Data Analysis (MySQL):** 
   - Loaded the cleaned data into **MySQL**.
   - Wrote complex SQL queries to extract key business insights, content distribution patterns, and ratings breakdown.
3. **Interactive Dashboard (Power BI):** 
   - Connected Power BI to visualize the insights through a clean, user-friendly interactive dashboard.

---

## 🛠 Tools & Technologies Used
* **Python:** Pandas, NumPy (Data Cleaning & Manipulation)
* **MySQL:** Database querying, aggregation, and exploratory analysis
* **Power BI:** Data modeling, DAX measures, and dashboard design
* **GitHub:** Version control and documentation

---

## 📈 Key Insights Discovered via SQL & Power BI
* **Content Split:** Analyzed the exact ratio between Movies and TV Shows on the platform.
* **Country-wise Production:** Identified top countries producing the highest volume of content.
* **Release Trends:** Tracked yearly growth and expansion of Netflix's content library.
* **Rating Demographics:** Evaluated content classification based on age groups and maturity ratings.
